# Real-Time Collaborative Kanban Board

A multi-organization and multi-tenant
real-time collaborative task management application.

## Tech Stack

- Node.js
- Express.js
- React.js
- PostgreSQL
- Prisma ORM
- Socket.IO

## Features

- Multi-Organization
- Multi-Tenant Architecture
- Role-Based Access Control
- Real-Time Collaboration
- Drag and Drop
- Activity Logs
- Conflict Resolution

## Frontend setup

From `frontend`, install dependencies, copy `.env.example` to `.env`, then run `npm run dev`. The example points the UI to the backend at `http://localhost:5000/api`.
